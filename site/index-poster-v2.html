TransPub
Pipeline Quickstart GitHub

English books can be translated, summarized, and published as audiobook websites.

TransPub is an open-source pipeline that transforms PDF / EPUB books into fully translated Chinese audiobook websites with AI‑generated summaries — deployed to GitHub Pages.

Features

PDF & EPUB support

Extracts chapters from TOC outlines with intelligent pattern-matching fallback for books without structured metadata.

Fully resumable

Every step is checkpointed to disk. Process interrupted? Re-run the same command and it picks up exactly where it stopped.

Single command

One shell script takes a raw book file all the way to a deployed website. Batch mode processes entire libraries.

Quickstart
# Clone and install
git clone https://github.com/jinghan23/TransPub
pip install -r requirements.txt

# Process a book (extract → translate → summarize → audio → website)
./process_book.sh "books/my-book.pdf" "my-book" "My Book Title"

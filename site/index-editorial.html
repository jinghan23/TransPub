Open-source book pipeline

Turn any book into a translated audiobook website

An automated pipeline that transforms English PDF / EPUB books into fully translated Chinese websites with AI-generated summaries and audio.

Features
Built for real reading

PDF & EPUB

Handles both formats. Extracts chapters from TOC outlines with pattern-matching fallback.

Resumable

Every step is checkpointed. Interrupted? Just re-run. It picks up where it left off.

One command

Single shell script from raw book to deployed website. Batch processing for multiple books.

Get started
Three lines to your first book
# Clone and setup
git clone https://github.com/jinghan23/TransPub
pip install -r requirements.txt

# Process a book
./process_book.sh "books/my-book.pdf" "my-book" "My Book Title"
